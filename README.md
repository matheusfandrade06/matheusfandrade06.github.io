### 📂 Projeto em Destaque: PROTOCOL

O projeto 'PROTOCOL' representa meu interesse de unir a contabilidade Tributária com a tecnologia, criando projetos que envolve o desenvolvimento de sites e aplicativos direcionados para a área contábil buscando resolver conflitos reais.
 
A primeira fase desse projeto foi a 'Calculadora Tributária' - um simulador avançado para profissionais autônomos que buscam entender a tributação sobre seus negócios e comparar cenários possíveis.

### 👨‍💻 Sobre Mim

Sou um estudante de Computação apaixonado por transformar regras de negócio complexas em interfaces simples e intuitivas. Com uma pós-graduação em Contabilidade Tributária, possuo a habilidade única de entender as dores do setor financeiro e traduzi-las em código eficiente.
